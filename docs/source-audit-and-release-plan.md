## Existing stack and features to preserve

The frontend is a plain HTML/CSS/JavaScript PWA, assembled by Python `tools/build.py` from `tools/base.html`, vocabulary, perception, command/agent, cloud, screen and offline modules into `web/index.html`. `web/backend.js` handles session bootstrap and `web/config.js` supplies the API location. There is no React/Next.js migration requirement. Capacitor wraps the same web assets in the existing Android and iOS projects with application ID `com.astha.companion`.

The backend is Node ESM with Express 4, signed cookie/bearer JWT sessions, scrypt PIN hashing, Nano ID and built-in `node:sqlite` with WAL. SQL bindings and user-scoped memory/room routes are existing foundations. SQLite tables include users, memories, rooms, events, agent tasks and knowledge documents. Node >=22.5 is required for the current database implementation.

Local perception tries YOLO26n ONNX through ONNX Runtime Web, then COCO-SSD/TensorFlow.js. Quantized CLIP supplies open vocabulary; Tesseract supplies OCR; Depth Anything V2 supplies relative depth; Whisper tiny supplies optional on-device speech recognition. Cloud routes use server Gemini/Gigalogy or an explicit personal-provider configuration. Spoken output uses server Microsoft/Edge speech or browser synthesis. Face and voice enrollment are implemented separately from PIN/session authentication.
